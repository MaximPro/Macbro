## 📖 Was ist das?

**Macbro** ist eine umfassend kuratierte Sammlung von macOS Automation Resources, entstanden aus der Analyse von 20+ top GitHub Repositories zu:

- 🔧 **Automator & Services** - Systemweite Rechtsklick-Automatisierung
- 📜 **AppleScript** - Native macOS Scripting
- 🔮 **Alfred Workflows** - Application Launcher Power
- ⌨️ **Keyboard Maestro** - Macro Automation
- 🚀 **Raycast Extensions** - Moderne Alternative
- 🎛️ **BetterTouchTool** - Gestures & TouchBar
